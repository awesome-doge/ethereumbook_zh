# 前言

這本書由我（Carlo Parisi，又名 Blackie）、Alessandro Mazza 與 Niccolò Pozzolini 共同完成。第一版由 Andreas M. Antonopoulos 與 Gavin Wood 博士在 2016 年到 2019 年間寫成，當然也深深影響了我們的寫作。

2023 年 11 月，一連串非常幸運的巧合讓我和 Andreas 在格拉斯哥碰了面。喝了幾杯啤酒、請他簽了幾次名之後，我問他有沒有打算寫《精通以太坊》的第二版。我會這麼問，是因為第一版雖然是一部傑作，內容卻已經跟不上時代：它在 2019 年出版，當時以太坊還在使用工作量證明（PoW），發展路線圖也和現在大不相同。

Andreas 的回答是他沒有寫第二版的打算，但那次談話卻激發了一個想法，最後促使我接下這個計畫。在格拉斯哥見面後不到一天，我就已經在和 O'Reilly 討論撰寫第二版的可能性了。

我馬上就知道，這會是一項龐大又重要的任務。能得到這個機會，我深感榮幸，但也擔心自己沒辦法做得夠好。我多年來一直是 Andreas 作品的愛好者；早在 2014 到 2015 年間，我之所以能那麼深入地理解比特幣，都要歸功於他。所以我知道，我需要幫手。

我第一個想到的人是 Alessandro。機會一成真，我就傳訊息問他要不要加入，所以計畫才開始沒幾個小時，他就參與其中了。他立刻開心地答應了（當時他完全不知道任何條件，甚至不知道這份工作有沒有酬勞）。

Niccolò 就比較難說服了。他整整拒絕了一個月，我才終於把他拉進來。幸好我非常固執，不肯接受「不」這個答案。一個月後，他終於點頭答應。至此，我們的團隊全員到齊，《精通以太坊（第二版）》的計畫也正式啟動。

我希望每一位讀者都能從這本書中學到至少一點東西。《精通以太坊》這本書教會了我和成千上萬的讀者非常多的東西，而我們也努力維持同樣的品質。這本書花了兩年的研究與寫作才完成，如果說這很容易，那我就是在說謊。

我們也非常自豪，這個計畫是由一支全義大利人的團隊完成的。希望這也能讓義大利的加密貨幣社群感到些許驕傲。

## 如何使用本書

本書既可以當作參考手冊，也可以從頭到尾讀完，完整探索以太坊。前兩章是循序漸進的入門介紹，適合新手使用者；這兩章的範例，只要具備一點技術能力的人都能完成。讀完這兩章，你就能掌握基礎知識，並使用以太坊的基本工具。第 3 章以後的部分內容是寫給程式設計師的，包含許多技術主題與程式設計範例，但大致上仍然是任何人都能讀懂的。

為了同時兼顧參考手冊與從頭讀到尾的敘述，本書難免有些重複的地方。有些主題（例如 gas）必須及早介紹，其他主題才講得通，但各自的章節還會再詳細說明。

最後，讀者可以透過本書的索引，依關鍵字輕鬆找到非常具體的主題與相關章節。

## 目標讀者

本書大致上適合所有人閱讀。這本書會教你智能合約區塊鏈如何運作、如何使用，以及如何在上面開發智能合約與去中心化應用（DApp）。前幾章也很適合初學者，作為深入認識以太坊的入門。

## 程式碼範例

本書的範例以 Solidity、Vyper 與 JavaScript 示範，並使用類 Unix 作業系統的命令列。只要為對應的語言安裝最基本的編譯器、直譯器與函式庫，所有程式碼片段都能在大多數作業系統上重現。必要時，我們會提供基本的安裝說明，並逐步示範這些指令的輸出。

所有程式碼片段都盡可能使用真實的數值與計算，所以你可以一個範例接著一個範例做下去，而且只要你自己寫程式計算同樣的值，都會看到相同的結果。例如，書中的私鑰以及對應的公鑰與地址都是真實的。範例中的交易、合約、區塊與區塊鏈參照，也都已經實際送上以太坊區塊鏈，成為公開帳本的一部分，你可以自行查看。

## 本書中的以太坊地址與交易

本書使用的以太坊地址、交易、金鑰、QR code 與區塊鏈資料，大部分都是真實的。也就是說，你可以瀏覽區塊鏈、查看書中作為範例的交易，用你自己的腳本或程式取得這些資料，諸如此類。

不過請注意，用來產生書中地址的私鑰都已經「燒毀」了。這表示如果你把錢送到這些地址中的任何一個，這筆錢不是永遠遺失，就是（更可能）被別人拿走，因為任何讀過本書的人，都能用書中印出的私鑰把錢取走。
